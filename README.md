# Payment Processing System

This is a secure web-based payment checkout system developed as part of my Information Technology coursework at Chinhoyi University of Technology.

## Features
* Secure form validation using JavaScript to ensure data accuracy.
* Backend payment processing logic using PHP.
* Database management using MySQL to store transaction data.
* User session management to remember payment details.
* Responsive styling using CSS.

## Technologies Used
* HTML5
* CSS3
* JavaScript
* PHP
* MySQL

## Setup Instructions
1. Import the `paymentsystem.sql` file into your MySQL database.
2. Update the database credentials in `config.php`.
3. Run the project on a local server (like XAMPP).
